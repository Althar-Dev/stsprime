# **App Name**: STS Pedia

## Core Features:

- Game & Service Catalog: An organized visual grid of available games, mobile data, and credit services for easy selection.
- Simplified Top-up Form: A high-performance interface for entering user IDs and selecting credit denominations with instant validation.
- Real-time Order Status Tracker: A dynamic dashboard showing the real-time fulfillment status of every transaction.
- Personal Top-up Ledger: A history view where users can revisit previous purchases and re-order with a single click.

## Style Guidelines:

- Primary color: Vibrant Electric Indigo (#8b71f9) symbolizing energy and modern tech connectivity.
- Background color: Deep midnight violet (#0f0d14), providing a high-contrast dark scheme tailored for gamers.
- Accent color: Celestial Soft Blue (#8aa2f8), used for interactive highlights and status badges.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-forward character. Body font: 'Inter' (sans-serif) for maximum readability in data tables.
- Minimalist geometric icons with thin strokes to maintain a clean, high-end fintech aesthetic.
- Modular card-based layout inspired by modern bento grids, ensuring a mobile-first responsive experience.
- Subtle neon glowing pulses for active transactions and smooth page transitions using framer-motion.
